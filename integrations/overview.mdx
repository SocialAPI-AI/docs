The SocialAPI MCP server lets an AI client run SocialAPI operations on your connected accounts through the [Model Context Protocol](https://modelcontextprotocol.io) (MCP). Once a client is connected, you can ask it in plain language to list your connected accounts, read and reply to comments, send direct messages (DMs), answer reviews, and publish or schedule posts.

The server URL is the same for every client:

```text
https://api.social-api.ai/mcp
```

The server uses the Streamable HTTP transport. Every tool runs the same operation as its REST equivalent, with the same scopes, plan allowances, and platform support: see [MCP tools reference](/integrations/tools).

## Authentication

An MCP client authenticates with a bearer token on the `Authorization` header. SocialAPI accepts the same two token types as the REST API:

| Token | Use it for | How the client gets it |
|---|---|---|
| OAuth 2.1 access token | Interactive clients with a built-in sign-in: Claude, ChatGPT, Le Chat, Cursor, VS Code, Codex, Hermes Agent, OpenClaw | You add the server URL. The client opens a SocialAPI sign-in page, you approve, and the client keeps and refreshes the token. See [OAuth for MCP clients](/integrations/oauth) |
| API key | Headless agents, servers, CI jobs, and clients without OAuth | You create a key in the dashboard and put it in the client's `Authorization` header. See [Custom MCP clients](/integrations/custom) |

A full-access API key and an OAuth access token can run every tool. To give an agent less, connect it with a [scoped API key](/guides/scoped-keys): a tool outside the key's scopes returns a result with `isError: true` and `code` `auth.insufficient_scope`. `required_scope` is absent for tools that need a full-access key: see [Scoped API keys](/guides/scoped-keys). See [Authentication](/guides/authentication) for both token types.

## What the agent can do

The agent gets one tool per operation: accounts and brands, comments, DMs, reviews, mentions, Automations, posts, media, analytics, exports, webhooks, events, usage, and API keys. [MCP tools reference](/integrations/tools) lists every tool by area with the REST endpoint it runs.

## Not the documentation MCP server

This documentation site also exposes its own MCP server, which only searches these docs. It cannot read or change your accounts. To manage your SocialAPI accounts from an AI client, add the server at `https://api.social-api.ai/mcp`.

## Troubleshooting

<AccordionGroup>
  <Accordion title="The sign-in window does not open or loops">
    Allow pop-ups for the client's site. Ad blockers and privacy extensions can block the redirect back to the client: pause them and retry.
  </Accordion>
  <Accordion title="Tool calls fail with HTTP 401">
    The client's OAuth session expired or its API key is wrong. Remove the SocialAPI server from the client and add it again to sign in again. For an API key, check that it is active in the [dashboard](https://app.social-api.ai/api-configuration?tab=keys). The `401` body is `{"error": "<message>"}`.
  </Accordion>
  <Accordion title="The client reports that the server is not responding">
    Check that the URL is exactly `https://api.social-api.ai/mcp`, with no trailing slash and no path after `/mcp`. Check [status.social-api.ai](https://status.social-api.ai) for an incident.
  </Accordion>
  <Accordion title="A tool returns an error result">
    A failed tool returns `isError: true` with the same `code` the REST API returns. Look the code up in [Errors](/guides/errors).
  </Accordion>
</AccordionGroup>
