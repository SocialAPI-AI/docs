Connect SocialAPI to VS Code and ask Copilot Chat in Agent mode to list your connected accounts, reply to comments, send DMs, and publish posts. VS Code connects to SocialAPI's MCP server at `https://api.social-api.ai/mcp` and signs in with OAuth 2.1, so you create no API key.

## Prerequisites

- [VS Code](https://code.visualstudio.com) 1.101 or later with the [GitHub Copilot](https://marketplace.visualstudio.com/items?itemName=GitHub.copilot) extension.
- A GitHub Copilot subscription: Individual, Business, or Enterprise.
- A SocialAPI account with at least one connected account.

## Set up with the config file

<Steps>
  <Step title="Add the server">
    Create or edit `.vscode/mcp.json` in your workspace, or add the entry to your user profile for all workspaces:

    ```json
    {
      "servers": {
        "SocialAPI": {
          "type": "http",
          "url": "https://api.social-api.ai/mcp"
        }
      }
    }
    ```
  </Step>
  <Step title="Authorize">
    VS Code shows a CodeLens above the server entry. Click **Auth** and authorize in the browser window that opens.
  </Step>
</Steps>

## Set up with the Command Palette

<Steps>
  <Step title="Add the server">
    Open the Command Palette (`Ctrl+Shift+P` on Windows and Linux, `Cmd+Shift+P` on macOS) and run **MCP: Add Server**. Select **HTTP** as the server type and enter `https://api.social-api.ai/mcp`.
  </Step>
  <Step title="Choose a scope">
    Choose **Global** for your user profile or **Workspace** for this workspace.
  </Step>
  <Step title="Authorize">
    Click the **Auth** CodeLens and authorize in the browser window that opens.
  </Step>
</Steps>

## Try it

Open **Copilot Chat**, switch to Agent mode, and ask:

```text
List my connected social accounts
```

Copilot calls `social_api_list_accounts` and answers with your connected accounts and their platforms.

## Troubleshooting

<AccordionGroup>
  <Accordion title="The Auth CodeLens does not appear">
    Check that VS Code is version 1.101 or later and that the GitHub Copilot extension is installed and active. The CodeLens appears above the server entry in `.vscode/mcp.json`.
  </Accordion>
  <Accordion title="The server does not connect">
    Check that the `url` is exactly `https://api.social-api.ai/mcp` and that `type` is `http`.
  </Accordion>
  <Accordion title="Tool calls fail with HTTP 401">
    The OAuth session expired. Click **Auth** above the server entry again to sign in again.
  </Accordion>
</AccordionGroup>
