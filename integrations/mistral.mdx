title: "Mistral / Le Chat"
description: "Connect SocialAPI to Le Chat from Mistral on web and mobile with a custom MCP connector to manage comments, DMs, and posts."
---

Connect SocialAPI to Le Chat and ask it to list your connected accounts, reply to comments, send DMs, and publish posts. Le Chat connects to SocialAPI's MCP server at `https://api.social-api.ai/mcp` and signs in with OAuth 2.1, so you create no API key.

## Prerequisites

- A SocialAPI account with at least one connected account.
- A Le Chat account on any plan. MCP connectors are available on the Free plan.

## Set up on web

<Steps>
  <Step title="Open Connectors">
    Open [chat.mistral.ai](https://chat.mistral.ai), open the side panel, expand **Intelligence**, and click **Connectors**.
  </Step>
  <Step title="Add a custom connector">
    Click **+ Add Connector** on the right, then select the **Custom MCP Connector** tab.

    <img
      src="/images/mcp-lechat-settings.png"
      alt="Le Chat custom MCP connector form"
    />
  </Step>
  <Step title="Fill in the form">
    - **Connector name:** `SocialAPI`
    - **Connection server:** `https://api.social-api.ai/mcp`
    - **Description** (optional): `Manage social media accounts, posts, comments, DMs, and more`

    Click **Connect**.
  </Step>
  <Step title="Authorize with your SocialAPI account">
    Le Chat detects the OAuth 2.1 sign-in and opens the SocialAPI authorization page. Log in and click **Authorize**.

    <img
      src="/images/mcp-lechat-oauth.png"
      alt="Le Chat authorization screen for SocialAPI"
    />
  </Step>
  <Step title="Turn the connector on in a conversation">
    Click **Tools** (the four-squares icon) below the message box and check **SocialAPI**. You can also type `/SocialAPI` in the message box.
  </Step>
</Steps>

Le Chat asks for approval before each tool call. Select **Always Allow** to skip the prompt for that tool in future. Le Chat labels the Connectors feature as Beta.

## Use it on mobile (iOS and Android)

A connector you added on the web appears in the Le Chat mobile apps.

<Steps>
  <Step title="Add the connector on the web">
    Follow [Set up on web](#set-up-on-web).
  </Step>
  <Step title="Open the app">
    Open the Le Chat mobile app. The connector is already there.
  </Step>
  <Step title="Turn the connector on in a conversation">
    Open the **Tools** menu and check **SocialAPI**.
  </Step>
</Steps>

## Try it

Ask Le Chat:

```text
List my connected social accounts
```

Le Chat calls `social_api_list_accounts` and answers with your connected accounts and their platforms.

## Troubleshooting

<AccordionGroup>
  <Accordion title="Le Chat does not detect the sign-in">
    Use the URL exactly as shown: `https://api.social-api.ai/mcp`.
  </Accordion>
  <Accordion title="SocialAPI is missing from the Tools menu">
    Check that the connector shows as connected in **Intelligence** → **Connectors**. Then check **SocialAPI** in **Tools** for the conversation.
  </Accordion>
  <Accordion title="Tool calls fail with HTTP 401">
    The OAuth session expired. Remove the SocialAPI connector and add it again to sign in again.
  </Accordion>
</AccordionGroup>
