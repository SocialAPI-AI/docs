The [SocialAPI MCP server](/integrations/overview) gives an AI agent one tool per operation it can run on your SocialAPI account. Every tool name starts with `social_api_`. A tool runs the same operation as its REST equivalent, so the same [scopes](/guides/scoped-keys), plan allowances, platform support, and error codes apply.

An agent calls a tool with a JSON-RPC `tools/call` request. The arguments are the tool's input fields:

```json
{
  "jsonrpc": "2.0",
  "id": 7,
  "method": "tools/call",
  "params": {
    "name": "social_api_reply_to_comment",
    "arguments": {
      "account_id": "acc_01HZ9X3Q4R5M6N7P8V2K0W1J",
      "post_id": "17895695668004550",
      "comment_id": "17858893269000001",
      "text": "Thanks for watching! The full recipe is in our bio."
    }
  }
}
```

A tool that fails returns a result with `isError: true`. When the failure comes from the operation itself, the text is a JSON object with the same `code` the REST endpoint returns, the message in `error`, and any `meta` fields at the top level. This result comes from an API key without the `inbox:write` scope:

```json
{
  "jsonrpc": "2.0",
  "id": 7,
  "result": {
    "content": [
      {
        "type": "text",
        "text": "{\"code\":\"auth.insufficient_scope\",\"error\":\"This API key does not have the required scope: inbox:write\",\"required_scope\":\"inbox:write\"}"
      }
    ],
    "isError": true
  }
}
```

A missing or malformed argument returns a plain-text message instead, for example `account_id is required`.

Every tool except `social_api_get_more_tools` also accepts an optional `context` string argument: the goal the call serves, in one short sentence. Describe people by role, never by name, email, or ID. A call without `context` runs the same way as a call with it.

## Accounts and brands

| Tool | What it does | REST equivalent |
|---|---|---|
| `social_api_list_accounts` | List your connected accounts, optionally for one brand. Returns the `id` that every other tool takes as `account_id` | `GET /v1/accounts` |
| `social_api_connect_account` | Start connecting an account. On OAuth platforms it returns the `auth_url` the person opens to authorize access. On Telegram and Bluesky it connects the account at once and returns its `account_id`. Accepts `permissions`: see [Account permissions](/guides/permissions) | `POST /v1/accounts/connect` |
| `social_api_exchange_oauth` | Finish a connection by exchanging the authorization code | `POST /v1/oauth/exchange` |
| `social_api_list_pending_profiles` | List the Google Business Profiles a pending connection can connect | `GET /v1/accounts/pending/{connection_id}` |
| `social_api_select_pending_profile` | Connect the chosen Google Business Profile from a pending connection | `POST /v1/accounts/pending/{connection_id}/select` |
| `social_api_update_account_permissions` | Replace a connected account's permissions, or send `unrestricted: true` to give it every permission. Removing a permission deletes the data it covered: see [Account permissions](/guides/permissions#removing-a-permission-deletes-data) | `PATCH /v1/accounts/{id}` |
| `social_api_disconnect_account` | Disconnect a connected account | `DELETE /v1/accounts/{id}` |
| `social_api_get_creator_info` | Get a TikTok account's posting options: whether it can post, the allowed privacy level, maximum video duration, and comment, duet, and stitch settings | `GET /v1/accounts/{id}/creator-info` |
| `social_api_list_account_pages` | List the pages of a connected account, such as Facebook Pages | `GET /v1/accounts/{id}/pages` |
| `social_api_update_account_page` | Set a page as the default, or deactivate it | `PATCH /v1/accounts/{id}/pages/{pageId}` |
| `social_api_list_pinterest_boards` | List the boards of a Pinterest account | `GET /v1/accounts/{id}/boards` |
| `social_api_list_brands` | List your brands | `GET /v1/brands` |
| `social_api_create_brand` | Create a brand | `POST /v1/brands` |
| `social_api_update_brand` | Rename a brand | `PATCH /v1/brands/{id}` |
| `social_api_delete_brand` | Delete a brand and disconnect its accounts | `DELETE /v1/brands/{id}` |
| `social_api_create_invite` | Create an invite link that lets someone connect an account to a brand. Accepts `permissions` | `POST /v1/invites` |
| `social_api_list_invites` | List a brand's invites, active, expired, and used | `GET /v1/invites` |
| `social_api_revoke_invite` | Revoke an invite link | `DELETE /v1/invites/{id}` |

| `social_api_hide_comment` | Hide a comment from public view | `POST /v1/inbox/comments/{postId}/{commentId}/hide` |
| `social_api_unhide_comment` | Show a hidden comment again | `DELETE /v1/inbox/comments/{postId}/{commentId}/hide` |

| `social_api_unlike_comment` | Remove the connected account's like from a comment | `DELETE /v1/inbox/comments/{postId}/{commentId}/like` |
| `social_api_delete_comment` | Delete a comment from the platform | `DELETE /v1/inbox/comments/{postId}/{commentId}` |
| `social_api_moderate_comment` | Hide, unhide, or delete a comment by its `sapi_cmt_` ID, with `action` set to `hide`, `unhide`, or `delete` | The hide, unhide, and delete endpoints above |

## What tools do not cover

No tool creates, rotates, or edits an API key, and no tool deletes your SocialAPI account. Create keys in the [dashboard](https://app.social-api.ai) or with `POST /v1/keys` (see [Authentication](/guides/authentication)).

Among the operations available only through the REST API are:

- Uploading a file in the request body (`POST /v1/media/upload`). An agent uploads with `social_api_get_media_upload_url` instead.
- Inbox sync, inbound attachments, and message reactions (`/v1/inbox/sync`, `/v1/inbox/media/{id}`, `/v1/inbox/conversations/{id}/messages/{messageId}/reaction`).
- Creating, editing, and deleting Pinterest boards.
- The webhook event catalog (`GET /v1/webhooks/events`). The `social_api_create_webhook` description lists the event names.
- Importing posts (`POST /v1/posts/import`), refreshing an account's posts (`POST /v1/accounts/{id}/sync`), announcements (`GET /v1/announcements`), and the plan catalog (`GET /v1/billing/plans`).
- Every endpoint under `/v1/platforms/` except Instagram Stories: WhatsApp templates and phone numbers, Google Business Profile locations, platform summaries and insights.

## Errors and limits

- **Timeout**: a request to the MCP server that runs longer than 5 minutes is stopped.
- **Errors**: a failed tool returns `isError: true` with the same error code as its REST equivalent. Codes are listed in [Errors](/guides/errors).
- **Scopes**: an agent connected with a scoped API key can run only the tools its scopes allow. A tool outside them returns `auth.insufficient_scope` with the missing scope in `required_scope`. `required_scope` is absent for tools that need a full-access key. See [Scoped API keys](/guides/scoped-keys).
- **Cost**: a tool call consumes the same credits and plan allowances as its REST equivalent. See [Plans](/guides/plans).
- **Rate limits**: tools that publish or send messages are subject to the same posting and messaging caps as the REST API. See [Rate limits](/guides/rate-limits).
- **Annotations**: every tool declares `readOnlyHint`, `destructiveHint`, and `openWorldHint`. Clients read them to decide which calls need your confirmation.
