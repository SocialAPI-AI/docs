title: "Cursor"
description: "Connect SocialAPI to Cursor with a config file or the Settings UI so Agent mode can manage comments, DMs, and posts in plain language."
---

Connect SocialAPI to Cursor and ask Agent mode to list your connected accounts, reply to comments, send DMs, and publish posts. Cursor connects to SocialAPI's MCP server at `https://api.social-api.ai/mcp` and signs in with OAuth 2.1, so you create no API key and put no credentials in the config.

## Prerequisites

- [Cursor](https://cursor.com) installed.
- A SocialAPI account with at least one connected account.

## Set up with the config file

<Steps>
  <Step title="Add the server">
    Add this to the project config `.cursor/mcp.json` or the global config `~/.cursor/mcp.json`:

    ```json
    {
      "mcpServers": {
        "SocialAPI": {
          "url": "https://api.social-api.ai/mcp"
        }
      }
    }
    ```
  </Step>
  <Step title="Authorize">
    The first time you use a SocialAPI tool, Cursor opens your browser on the SocialAPI authorization page. Log in and click **Authorize**. Cursor stores and refreshes the token.
  </Step>
</Steps>

Cursor supports both the SSE and Streamable HTTP transports for remote servers.

## Set up with the Settings UI

<Steps>
  <Step title="Open MCP settings">
    Open **Cursor Settings** (gear icon) and go to **Tools & Integrations**.
  </Step>
  <Step title="Add the server">
    Under **MCP Tools**, click **Add Custom MCP** and enter `https://api.social-api.ai/mcp` as the URL.
  </Step>
  <Step title="Authorize">
    Click **Needs login** and authorize in the browser window that opens.
  </Step>
</Steps>

## Try it

Open **Agent** mode and ask:

```text
List my connected social accounts
```

SocialAPI tools appear under **Available Tools**, and Cursor calls them when a request needs them. You can also name a tool in your prompt. Cursor calls `social_api_list_accounts` and answers with your connected accounts and their platforms.

## Troubleshooting

<AccordionGroup>
  <Accordion title="The connection fails">
    Open the **Output** panel (`Cmd+Shift+U` on macOS, `Ctrl+Shift+U` on Windows and Linux) and select **MCP Logs** in the dropdown. Check that the URL is exactly `https://api.social-api.ai/mcp`.
  </Accordion>
  <Accordion title="The server shows Needs login">
    Click **Needs login** to run the sign-in. Authorization has not happened yet, or the session expired.
  </Accordion>
  <Accordion title="Tool calls fail with HTTP 401">
    The OAuth session expired. Remove the SocialAPI server from Cursor and add it again to sign in again.
  </Accordion>
</AccordionGroup>
