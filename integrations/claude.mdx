title: "Claude"

Connect SocialAPI to Claude and ask it to list your connected accounts, reply to comments, send DMs, and publish posts. Claude connects to SocialAPI's MCP server at `https://api.social-api.ai/mcp` and signs in with OAuth 2.1, so you create no API key.

## Prerequisites

- A SocialAPI account with at least one connected account.
- For claude.ai, Claude Desktop, and mobile: a Claude Free, Pro, Max, Team, or Enterprise plan.
- For Claude Code: [Claude Code](https://docs.claude.com/en/docs/claude-code) installed and signed in.

Claude Desktop, claude.ai, and the mobile app share one account. A connector you add on one surface appears on the others.

## Set up claude.ai

<Steps>
  <Step title="Open Connectors">
    Click your profile icon, then go to **Settings** → **Connectors**. You can also open [claude.ai/customize/connectors](https://claude.ai/customize/connectors).

    <img
      src="/images/mcp-claude-settings.png"
      alt="Claude Settings page with the Connectors section"
    />
  </Step>
  <Step title="Connect SocialAPI">
    SocialAPI is in Claude's connectors directory. Search for **SocialAPI** and click **Connect**. Claude already knows the server URL, so you type nothing.

    <img
      src="/images/mcp-claude-directory.png"
      alt="SocialAPI connector in the Claude connectors directory"
    />

    On a Team plan, a member who cannot enable connectors sees **Request** instead of **Connect**. The request goes to an organization admin, who enables the connector in **Organization settings** → **Connectors**. The member then clicks **Connect** in **Settings** → **Connectors**.
  </Step>
  <Step title="Authorize with your SocialAPI account">
    A browser window opens on the SocialAPI authorization page. Log in and click **Authorize**. The window closes when the sign-in is done.

    <img
      src="/images/mcp-claude-oauth.png"
      alt="SocialAPI authorization screen"
    />
  </Step>
  <Step title="Turn the connector on in a conversation">
    Open a new conversation, click **+** at the bottom left of the input, select **Connectors**, and switch **SocialAPI** on.

    <img
      src="/images/mcp-claude-conversation.png"
      alt="Claude conversation using SocialAPI tools to list accounts"
    />
  </Step>
</Steps>

## Set up Claude Desktop

Claude Desktop adds remote servers through **Settings** → **Connectors**, the same flow as claude.ai.

<Steps>
  <Step title="Open Connectors">
    In Claude Desktop ([download](https://claude.ai/download)), go to **Settings** → **Connectors**.
  </Step>
  <Step title="Add SocialAPI">
    Search the directory for **SocialAPI** and click **Connect**. To add it by URL instead, click **Add custom connector** (the Free plan allows 1 custom connector), enter `SocialAPI` as the name and `https://api.social-api.ai/mcp` as the URL.
  </Step>
  <Step title="Authorize">
    Complete the sign-in in the browser window that opens.
  </Step>
</Steps>

<Warning>
  `claude_desktop_config.json` holds local stdio servers only (`command` and `args`). A remote server such as SocialAPI cannot go in that file: add it in **Settings** → **Connectors**.
</Warning>

## Set up Claude Code

<Steps>
  <Step title="Add the server">
    ```bash
    claude mcp add socialapi --transport http https://api.social-api.ai/mcp
    ```

    By default the server is added to the local scope, which is the current project only. Add `--scope user` to use it in all projects, or `--scope project` to share it through `.mcp.json`:

    ```bash
    claude mcp add socialapi --transport http --scope user https://api.social-api.ai/mcp
    ```
  </Step>
  <Step title="Authorize">
    Run `/mcp` in Claude Code, select **SocialAPI**, and complete the sign-in in your browser. You can also run `claude mcp login socialapi`. Log in and click **Authorize**. On a machine without a browser, Claude Code prints the authorization URL for you to open elsewhere.
  </Step>
  <Step title="Check the server">
    ```bash
    claude mcp list
    ```

    To remove the server, run `claude mcp remove socialapi`.
  </Step>
</Steps>

## Set up mobile (iOS and Android)

<Steps>
  <Step title="Open Connectors">
    In the Claude app, tap your profile icon, then go to **Settings** → **Connectors**.
  </Step>
  <Step title="Connect SocialAPI">
    Search for **SocialAPI** and tap **Connect**.
  </Step>
  <Step title="Authorize">
    Complete the sign-in in the browser sheet that opens.
  </Step>
  <Step title="Turn the connector on in a conversation">
    Open the **+** menu, select **Connectors**, and switch **SocialAPI** on.
  </Step>
</Steps>

## Try it

Ask Claude:

```text
List my connected social accounts
```

Claude calls `social_api_list_accounts` and answers with your connected accounts and their platforms. Then try "Show me the latest comments on my Instagram posts".

## Troubleshooting

<AccordionGroup>
  <Accordion title="Connect shows Request instead">
    Your Team plan does not let you enable connectors yourself. Send the request, and an organization admin enables SocialAPI in **Organization settings** → **Connectors**.
  </Accordion>
  <Accordion title="Claude Code does not open a browser">
    Claude Code uses your system default browser. Set one, or run `claude mcp login socialapi --no-browser` and open the authorization URL that Claude Code prints.
  </Accordion>
  <Accordion title="SocialAPI tools are missing in a conversation">
    Open **+** → **Connectors** and check that **SocialAPI** is on. A conversation does not use a connector that is off.
  </Accordion>
  <Accordion title="Tool calls fail with HTTP 401">
    The OAuth session expired. Remove the SocialAPI connector and add it again to sign in again.
  </Accordion>
</AccordionGroup>
