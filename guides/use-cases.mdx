SocialAPI is a REST API and MCP server for the comments, direct messages (DMs), mentions, reviews, and posts of your connected social accounts. These are 5 common ways to use it, each with the guide that has the details.

## Read and answer an inbox

Read the comments, DMs, mentions, and reviews of every connected account through one set of endpoints, and answer them. Each area has its own guide: [Comments](/guides/comments), [Direct messages](/guides/direct-messages), [Reviews](/guides/reviews), and [Mentions](/guides/mentions).

```bash
curl https://api.social-api.ai/v1/inbox/conversations \
  -H "Authorization: Bearer $SOCAPI_KEY"
```

Start with [Unified inbox](/guides/inbox). Receive new items as they arrive with [Webhooks](/guides/webhooks).

## Answer comments and DMs automatically

An Automation answers Instagram and Facebook comments and DMs that match keywords: a private reply with a link, a public reply, a hidden comment, or a button menu. SocialAPI runs it, so you run no server. On Instagram, a Follow gate sends the link only to people who follow the account.

```bash
curl -X POST https://api.social-api.ai/v1/automations \
  -H "Authorization: Bearer $SOCAPI_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "account_id": "acc_01HZ9X3Q4R5M6N7P8V2K0W1J",
    "name": "Send the link",
    "trigger": "comment",
    "steps": [{
      "key": "start",
      "filters": [{ "type": "keyword", "keyword": { "keywords": ["link"], "match": "contains" } }],
      "actions": [{ "type": "private_reply", "private_reply": { "texts": ["Here is the link: https://example.com"] } }]
    }]
  }'
```

See [Automations](/guides/automations).

## Publish to many platforms

Send one post to 1 or more connected accounts with one request, and read the status of each platform's copy. Add media with [Media](/guides/media). Required fields differ per platform: Instagram, for example, needs an image or video ([Instagram publishing](/platforms/instagram/publishing)).

```bash
curl -X POST https://api.social-api.ai/v1/posts \
  -H "Authorization: Bearer $SOCAPI_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "text": "Hello from SocialAPI!",
    "media": [{ "source_type": "url", "source": "https://cdn.example.com/launch.jpg" }],
    "platform_data": { "instagram": { "content_type": "feed" } },
    "publish_now": true,
    "targets": [
      { "account_id": "acc_01HZ9X3Q4R5M6N7P8V2K0W1J" },
      { "account_id": "acc_01HZ9X4T6B8C2D5F7G9H1J3K" }
    ]
  }'
```

See [Publishing](/guides/publishing) and [Track post delivery](/guides/delivery).

## Schedule posts

Set `scheduled_at` instead of `publish_now` to publish at a time you choose. Edit, reschedule, or cancel the post before that time.

```bash
curl -X POST https://api.social-api.ai/v1/posts \
  -H "Authorization: Bearer $SOCAPI_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "text": "Our spring sale starts today.",
    "media": [{ "source_type": "url", "source": "https://cdn.example.com/launch.jpg" }],
    "platform_data": { "instagram": { "content_type": "feed" } },
    "scheduled_at": "2026-10-20T09:00:00Z",
    "targets": [{ "account_id": "acc_01HZ9X3Q4R5M6N7P8V2K0W1J" }]
  }'
```

See [Scheduling](/guides/scheduling).

## Give an AI agent access

The MCP server gives an agent in Claude, ChatGPT, or Cursor tools to read the inbox, reply, publish, and manage Automations and accounts. The operations listed under [What tools do not cover](/integrations/tools#what-tools-do-not-cover) are REST only. Give an agent a [scoped API key](/guides/scoped-keys) to limit what it can do.

See [MCP server](/integrations/overview) and [MCP tools reference](/integrations/tools).
