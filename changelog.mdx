<Update label="2026-10-13" description="Documentation" tags={["Documentation"]}>
  ## Documentation restructure

  The documentation has new URLs, grouped into Guides, Platforms, AI agents, and API reference. Old URLs redirect to the new pages. Start at [Supported platforms](/platforms/overview).
</Update>

<Update label="2026-10-13" description="Pinterest" tags={["Pinterest"]}>
  ## Pinterest boards

  AI agents can list a Pinterest account's boards with `social_api_list_pinterest_boards`. See [MCP tools reference](/integrations/tools).
</Update>

<Update label="2026-10-12" description="Instagram" tags={["Analytics", "Instagram"]}>
  ## Per-post Instagram insights

  `GET /v1/posts/{pid}/metrics` now returns insights for an Instagram post, such as views, reach, interactions, and saves. See [Instagram live metrics](/platforms/instagram/publishing#live-metrics-and-insights).
</Update>

<Update label="2026-10-12" description="LinkedIn" tags={["Publishing", "LinkedIn"]}>
  ## LinkedIn escapes reserved characters

  Characters LinkedIn reserves for formatting are escaped, so plain text appears as typed. Hashtags and mentions still use the syntax in [Text formatting](/platforms/linkedin/publishing#text-formatting).
</Update>

<Update label="2026-10-06" description="Accounts" tags={["Analytics"]}>
  ## Sync cooldown per account

  `POST /v1/accounts/{id}/sync` allows 1 request per account every 5 minutes. A second request inside the window returns `429 accounts.sync_rate_limited`. See [Refresh an account's posts](/guides/analytics#refresh-an-accounts-posts).
</Update>

<Update label="2026-10-06" description="Instagram and Facebook" tags={["Publishing", "Instagram", "Facebook"]}>
  ## Photos and videos on post targets

  Instagram and Facebook post targets return `platform_media`, the images and videos of the published post, including posts published outside SocialAPI. See [Instagram publishing](/platforms/instagram/publishing).
</Update>

<Update label="2026-09-29" description="Automations" tags={["Automations"]}>
  ## Multi-step Automations, buttons, and the Follow gate

  Automations run multi-step flows with postback buttons, and Instagram Automations can send a link only to people who follow the account. See [The Follow gate](/guides/automations#the-follow-gate).
</Update>

<Update label="2026-09-28" description="Automations" tags={["Automations"]}>
  ## Keyword Automations

  An Automation on an Instagram or Facebook account can react only to comments or messages that contain your keywords. See [Automations](/guides/automations).
</Update>

<Update label="2026-09-22" description="Analytics" tags={["Analytics"]}>
  ## Stored analytics history

  SocialAPI stores daily history for accounts, brands, and posts, and returns it from the account, brand, and post analytics endpoints. See [Analytics](/guides/analytics).
</Update>

<Update label="2026-09-17" description="Direct messages" tags={["Direct messages"]}>
  ## Reply to a specific message

  Messages carry `reply_to.platform_id` when they reply to an earlier message. See [Read messages](/guides/direct-messages#read-messages).
</Update>
