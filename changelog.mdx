<Update label="2026-10-16" description="Publishing" tags={["Publishing"]}>
  ## Stagger post targets

  `POST /v1/posts` and `social_api_create_post` accept `stagger` with `min_seconds` and `max_seconds`. The targets publish one after another in the order listed, each a random delay in that range after the previous one, starting at `scheduled_at` or immediately with `publish_now`. The post is returned as `scheduled`, and each target's planned time is in `targets[].scheduled_at`. `stagger` on a draft, or outside `0 <= min_seconds <= max_seconds <= 86400`, returns `400 validation.field_invalid`. See [Stagger targets](/guides/scheduling#stagger-targets).
</Update>

<Update label="2026-10-16" description="TikTok" tags={["Accounts", "TikTok"]}>
  ## TikTok creator connection

  `POST /v1/accounts/connect` for `tiktok` accepts `"metadata": {"connection_type": "creator"}`, which connects the account through TikTok's Content Posting API instead of TikTok API for Business, so a personal or creator account does not need to be a TikTok Business Account. A creator connection publishes posts and drafts, lists posts, and reads creator info and the account summary. It has no comments or mentions. Connects without `connection_type` are unchanged. See [Creator connection](/platforms/tiktok#creator-connection).
</Update>

<Update label="2026-10-16" description="YouTube" tags={["Inbox", "YouTube"]}>
  ## YouTube comments turned off, and rate-limit status

  Listing the comments of a YouTube video with comments turned off returns `422 platform.youtube.comments_disabled` instead of `501 resource.not_supported`. Stop polling that video until the channel owner turns comments back on. When the YouTube daily quota is used up, calls return `429 platform.youtube.rate_limit` as documented, instead of `502 platform.youtube.api_error`. See [YouTube](/platforms/youtube).
</Update>

<Update label="2026-10-15" description="LinkedIn" tags={["Accounts", "LinkedIn", "Beta"]}>
  ## LinkedIn profile analytics (beta)

  `GET /v1/platforms/linkedin/insights` now returns `kind` (`organization` or `member`). A LinkedIn personal profile connected with `connection_type` `profile` returns its follower count and counts for its 5 most recent posts published through SocialAPI, and `GET /v1/accounts` returns `connection_type` on these accounts. The profile connection requires beta access: an account without it gets `403 billing.platform_not_available`. See [Profile analytics](/platforms/linkedin#profile-analytics-beta).
</Update>

<Update label="2026-10-14" description="Publishing" tags={["Publishing"]}>
  ## Platform options on post targets

  Each post target returns `platform_data` with the platform-specific options you set when the post was created or last updated, so a saved post reopens with its options. Chain continuation posts are returned in segments, not in `platform_data`. See [Publishing](/guides/publishing#where-platform-data-goes).
</Update>

<Update label="2026-10-13" description="Accounts" tags={["Accounts"]}>
  ## Account permissions

  Send `permissions` on `POST /v1/accounts/connect` or `POST /v1/invites` to give a connected account only the permissions you need. `GET /v1/accounts` returns `permissions` and `effective_permissions`, and `PATCH /v1/accounts/{id}` changes them. A call the account lacks a permission for returns `403 account.permission_missing`, except publishing, which reports it on the target, and the other calls listed in [Account permissions](/guides/permissions#what-an-account-can-do-right-now).
</Update>

<Update label="2026-10-13" description="TikTok" tags={["Inbox", "Mentions", "TikTok"]}>
  ## TikTok comments and mentions

  TikTok accounts support comments: list comments and replies on the account's posts, reply to them, like them, hide comments other people wrote, and delete comments the connected account wrote. A `comment.received` event fires when someone else comments, and a TikTok Business Account can list the posts and comments that mention it and reply to a mention made in a comment. On a TikTok account connected before 2026-10-13, comment and mention calls return `501 resource.not_supported` until you reconnect the account. See [TikTok comments](/platforms/tiktok#comments) and [TikTok mentions](/platforms/tiktok#mentions).
</Update>

<Update label="2026-09-05" description="Direct messages" tags={["Direct messages", "Instagram", "Facebook", "WhatsApp"]}>
  ## Messaging velocity cap

  Your SocialAPI account can send 10 messages per minute in total across its Instagram, Facebook, and WhatsApp accounts. DMs, comment replies, private replies, and WhatsApp template messages all count, and a DM with more than one attachment counts one message per attachment. A send over the cap returns `429 messaging.velocity_limit` with `Retry-After`, and it spends no credit. See [Messaging velocity cap](/guides/rate-limits#messaging-velocity-cap).
</Update>

<Update label="2026-09-05" description="Direct messages" tags={["Direct messages", "Instagram", "Facebook"]}>
  ## Closed messaging windows return the same error

  After Instagram or Facebook refuses a DM because the 24-hour messaging window has closed, later sends to that conversation return the same `400` error code as the first refusal, with `meta.blocked_locally` set to `true`. The block lifts when the person messages you again, or 24 hours after the refusal, whichever comes first. Sends that carry a `message_tag` are never blocked this way. See [The messaging window](/guides/direct-messages#the-messaging-window).
</Update>

  The API hosts an MCP server at `/mcp`. MCP clients register and sign in with OAuth 2.1, and a consent page confirms access. See [OAuth](/integrations/oauth).
</Update>

  ## Annual billing

  Paid plans can be billed yearly at a 20% discount. See [Plans](/guides/plans).
</Update>

<Update label="2026-03-06" description="Comments" tags={["Inbox"]}>
  ## Comments are scoped to a post

  Breaking: `GET /v1/accounts/{id}/comments` is replaced by `GET /v1/accounts/{id}/posts/{pid}/comments`. Use `GET /v1/accounts/{id}/posts` to find post IDs. See [Comments](/guides/comments).
</Update>

<Update label="2026-03-01" description="Initial release" tags={["Accounts", "Inbox", "Instagram", "Webhooks", "Billing"]}>
  ## Initial release

  SocialAPI is open to public signups, with:

  - Instagram: connect accounts with `POST /v1/accounts/connect`, read comments, direct messages, and mentions, reply to comments, send direct messages, and moderate comments.
  - API keys: create, list, and revoke keys with `/v1/keys`.
  - Webhooks: create, list, update, and delete endpoints with `/v1/webhooks`.
  - Usage: `GET /v1/usage`, and account deletion with `DELETE /v1/users/me`.
  - Plans: paid plans with checkout and a billing portal in the dashboard.

  See [Quickstart](/quickstart).
</Update>
