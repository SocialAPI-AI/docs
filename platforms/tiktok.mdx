The TikTok API in SocialAPI connects a TikTok account through TikTok's authorization screen. It publishes videos and photo carousels, lists the account's videos with their counts, returns the creator settings that govern each post, and reads profile statistics. SocialAPI's own TikTok app connects the account, so you register nothing: see [Platform apps](/guides/platform-credentials).

## At a glance

| Field | Value |
|---|---|
| Platform slug | `tiktok` |
| Auth | OAuth 2.0 with TikTok Login |
| Platform API | TikTok Content Posting API v2 and Login Kit |
| Status | Available |

## Capabilities

An unsupported call returns `501 resource.not_supported`.

| Feature | Status | Condition |
|---|---|---|
| Publish a video | Yes | See [TikTok publishing](/platforms/tiktok/publishing) |
| Publish a photo carousel | Yes | 2 to 35 images |
| Send a video to the account's TikTok drafts | Yes | `post_mode: "inbox"`. Video only. The creator finishes the post in the TikTok app |
| Schedule a post | Yes | `scheduled_at` on the post |
| First comment on a post | No | `first_comment` is ignored |
| Update a published post | No | `PATCH /v1/posts/{pid}` returns `409 post.state_invalid` for a published post, and TikTok gives apps no edit call |
| Delete a published post | No | `DELETE /v1/posts/{pid}` returns `501 resource.not_supported` for the TikTok target and the post stays live. Delete it in the TikTok app |
| List posts | Yes | Videos with views, likes, comments, and shares. See [Sync videos](#sync-videos) |
| Creator info | Yes | Allowed privacy levels and interaction settings. See [Creator info](#creator-info) |
| Account summary | Yes | Follower, following, likes, and video counts. See [Account summary](#account-summary) |
| Comments, replies, moderation | No | `501 resource.not_supported` |
| DMs | No | `501 resource.not_supported` |
| Mentions | No | `501 resource.not_supported` |
| Reviews | No | TikTok has no reviews. `501 resource.not_supported` |
| Automations | No | `422 automation.platform_unsupported` |
| Analytics | Yes | See [Analytics](/guides/analytics) |
| Webhook events | Partial | `account.disconnected` and the `post.*` events. See [Webhook events](#webhook-events) |

The cross-platform matrix is on [Platforms](/platforms/overview).

## Connect an account

Connect with `POST /v1/accounts/connect` and `"platform": "tiktok"`. The shared flow, request fields, and result are in [Connect accounts](/guides/connect-accounts), and the redirect parameters are in [Redirect parameters](/guides/connect-accounts#redirect-parameters).

```bash
curl -X POST https://api.social-api.ai/v1/accounts/connect \
  -H "Authorization: Bearer $SOCAPI_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "platform": "tiktok",
    "redirect_uri": "https://app.example.com/oauth/callback",
    "state": "session_abc123"
  }'
```

Response (HTTP 200):

```json
{
  "auth_url": "https://www.tiktok.com/v2/auth/authorize/?client_key=sbaw1234&state=4a8f2c1e9b3d7f06a5c2e8b4d1f3a7e2",
  "state": "4a8f2c1e9b3d7f06a5c2e8b4d1f3a7e2"
}
```

TikTok-specific rules:

- **Profile data.** A connected TikTok account carries a `metadata` object with the profile counts read at connect time.
- **Reconnect.** If the access token is no longer valid, calls return `401 platform.tiktok.auth` and the account needs reconnecting. SocialAPI refreshes access tokens itself, so this happens when the person revoked access or the refresh token expired. See [Reconnect an account](/guides/connect-accounts#reconnect-an-account).
- **Older accounts.** An account connected before SocialAPI requested the `video.list` or `user.info.stats` permission needs one reconnect before the video list or the profile counts work.

```json
{
  "id": "acc_01HZ9X3Q4R5M6N7P8V2K0W1J",
  "platform": "tiktok",
  "name": "Acme Corp",
  "username": "acmecorp",
  "metadata": {
    "avatar_url": "https://p16.tiktokcdn.com/avatar.jpeg",
    "follower_count": 12400,
    "following_count": 180,
    "video_count": 94,
    "likes_count": 340000
  }
}
```

| Field | Type | Description |
|---|---|---|
| `avatar_url` | string | Profile picture URL |
| `follower_count` | integer | Number of followers |
| `following_count` | integer | Number of accounts the account follows |
| `video_count` | integer | Videos on the profile |
| `likes_count` | integer | Likes across all videos |

## Creator info

`GET /v1/accounts/{id}/creator-info` returns the settings TikTok applies to the creator's next post. Read it before you publish, because the allowed privacy levels differ per creator. It needs the `accounts:read` scope.

```bash
curl https://api.social-api.ai/v1/accounts/acc_01HZ9X3Q4R5M6N7P8V2K0W1J/creator-info \
  -H "Authorization: Bearer $SOCAPI_KEY"
```

Response (HTTP 200):

```json
{
  "platform": "tiktok",
  "nickname": "Acme Corp",
  "avatar_url": "https://p16.tiktokcdn.com/avatar.jpeg",
  "can_post": true,
  "max_video_duration_sec": 600,
  "privacy_level_options": ["PUBLIC_TO_EVERYONE", "MUTUAL_FOLLOW_FRIENDS", "SELF_ONLY"],
  "interaction_settings": {
    "comment_disabled": false,
    "duet_disabled": false,
    "stitch_disabled": false
  }
}
```

| Field | Description |
|---|---|
| `can_post` | `false` when TikTok lists no privacy level, which happens when the creator reached TikTok's daily posting limit |
| `max_video_duration_sec` | The longest video this creator can post, in seconds |
| `privacy_level_options` | The `privacy_level` values this creator can use |
| `interaction_settings` | `true` for a setting the creator turned off in TikTok. A post cannot turn that interaction back on |

Other platforms return `501 resource.not_supported` from this endpoint.

## Account summary

`GET /v1/platforms/tiktok/accounts/{id}/summary` reads the account's profile and counts from TikTok at the time of the call. It needs the `accounts:read` scope.

```bash
curl https://api.social-api.ai/v1/platforms/tiktok/accounts/acc_01HZ9X3Q4R5M6N7P8V2K0W1J/summary \
  -H "Authorization: Bearer $SOCAPI_KEY"
```

Response (HTTP 200):

```json
{
  "display_name": "Acme Corp",
  "username": "acmecorp",
  "avatar_url": "https://p16-sign.tiktokcdn-us.com/avatar.jpeg",
  "follower_count": 12400,
  "following_count": 87,
  "likes_count": 980000,
  "video_count": 47,
  "bio_description": "Spring collection out now.",
  "profile_deep_link": "https://www.tiktok.com/@acmecorp",
  "is_verified": false
}
```

TikTok grants the counts and the profile fields through separate permissions. When one is missing on the token, the fields it covers come back empty or `0` and the others are still filled. The call fails only when both are unavailable.

## Sync videos

`GET /v1/posts?platform=tiktok&account_ids={id}` lists the TikTok videos SocialAPI has synced, each with its `permalink` and `metrics` (`views`, `likes`, `comments`, `shares`). This includes videos published outside SocialAPI.

`POST /v1/platforms/tiktok/accounts/{id}/sync` pulls the 20 most recent videos from TikTok at once instead of waiting for the next background sync. It needs the `accounts:manage` scope.

```bash
curl -X POST https://api.social-api.ai/v1/platforms/tiktok/accounts/acc_01HZ9X3Q4R5M6N7P8V2K0W1J/sync \
  -H "Authorization: Bearer $SOCAPI_KEY"
```

Response (HTTP 200):

```json
{
  "success": true
}
```

## Webhook events

| Event | When it fires |
|---|---|
| `account.disconnected` | The person removed SocialAPI's app in TikTok's settings. SocialAPI disconnects and deletes the account, and the event carries `account_id`, `platform`, and `platform_user_id` |
| `post.published`, `post.partial`, `post.failed` | A post to this account finished: see [Delivery](/guides/delivery). A TikTok post can finish after the request that created it returned |

Every event is described in [Webhook events](/guides/webhook-events).

## Limits

| Limit | Value |
|---|---|
| Video caption | 2,200 UTF-16 characters |
| Photo caption | 90 UTF-16 characters |
| Photo carousel | 2 to 35 images, JPEG or WebP |
| Posts | 18 per 24 hours and 25 per hour for each account. TikTok's own cap is 20 per day: see [Posting velocity caps](/guides/rate-limits#posting-velocity-caps) |
| Videos per sync | 20 |
| TikTok's own rate limit | `429 platform.tiktok.rate_limit`. It costs no SocialAPI credit |

## Permissions

SocialAPI's TikTok app requests these scopes at connect. You apply for no app review.

| Scope | Used for |
|---|---|
| `user.info.basic` | Account identity, display name, and avatar |
| `user.info.profile` | Username, bio, profile link, and verification |
| `video.publish` | Publish videos and photo carousels as the creator |
| `video.upload` | Send a video to the creator's TikTok drafts |
| `video.list` | List the account's videos and their counts |
| `user.info.stats` | Follower, following, likes, and video counts |
