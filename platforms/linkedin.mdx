The LinkedIn API in SocialAPI connects a LinkedIn member profile (`linkedin`). A connection publishes text, image, video, multi-image, and link posts as the person. SocialAPI's own LinkedIn app connects the profile, so you register nothing: see [Platform apps](/guides/platform-credentials).

## At a glance

| Field | Value |
|---|---|
| Platform slug | `linkedin` |
| Auth | OAuth 2.0 with LinkedIn Sign In (OpenID Connect) |
| Platform API | LinkedIn Posts API |
| Status | Available |

## Capabilities

An unsupported call returns `501 resource.not_supported`.

| Feature | Status | Condition |
|---|---|---|
| Publish text, image, video, multi-image, link posts | Yes | See [LinkedIn publishing](/platforms/linkedin/publishing) |
| Schedule a post | Yes | `scheduled_at` on the post |
| First comment on a post | No | `first_comment` is ignored |
| Update a published post | No | `PATCH /v1/posts/{pid}` returns `409 post.state_invalid` for a published post. Delete the post and publish a new one |
| Delete a published post | Yes | |
| List posts | Partial | Returns the posts you published through SocialAPI, not a live read from LinkedIn |
| Comments, DMs, mentions | No | `501 resource.not_supported` |
| Reviews | No | LinkedIn has no reviews. `GET /v1/inbox/reviews/{account_id}` returns `422 account.platform_unsupported` |
| Automations | No | `422 automation.platform_unsupported` |
| Webhook events | Partial | `account.disconnected` and the `post.*` events |

The cross-platform matrix is on [Platforms](/platforms/overview).

## Connect an account

Connect with `POST /v1/accounts/connect` and `"platform": "linkedin"`. The shared flow, request fields, and result are in [Connect accounts](/guides/connect-accounts), and the redirect parameters are in [Redirect parameters](/guides/connect-accounts#redirect-parameters).

```bash
curl -X POST https://api.social-api.ai/v1/accounts/connect \
  -H "Authorization: Bearer $SOCAPI_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "platform": "linkedin",
    "redirect_uri": "https://app.example.com/oauth/callback",
    "state": "session_abc123"
  }'
```

Response (HTTP 200):

```json
{
  "auth_url": "https://www.linkedin.com/oauth/v2/authorization?response_type=code&client_id=77abc123&state=4a8f2c1e9b3d7f06a5c2e8b4d1f3a7e2",
  "state": "4a8f2c1e9b3d7f06a5c2e8b4d1f3a7e2"
}
```

LinkedIn-specific rules:

- **Member connection.** The connected account is the person who signed in. Posts publish to that person's feed.
- **Token lifetime.** LinkedIn access tokens last about 60 days and cannot be refreshed. When one expires, calls return `401 platform.linkedin.auth` and the person reconnects the account. See [Reconnect an account](/guides/connect-accounts#reconnect-an-account).
- **Disconnect.** LinkedIn offers apps no way to end an authorization. Disconnecting an account removes it from SocialAPI, and the person removes SocialAPI's app in their LinkedIn settings.

## Webhook events

| Event | When it fires |
|---|---|
| `account.disconnected` | SocialAPI flagged the account for reconnection. The event carries `reconnect_required: true` and a `reason` |
| `post.published`, `post.partial`, `post.failed` | A post to this account finished: see [Delivery](/guides/delivery) |

Every event is described in [Webhook events](/guides/webhook-events).

## Limits

| Limit | Value |
|---|---|
| Post text | 3,000 characters |
| Multi-image post | 2 to 20 images |
| Posts | 25 per hour and 50 per 24 hours for each account: see [Posting velocity caps](/guides/rate-limits#posting-velocity-caps) |
| LinkedIn's own rate limit | `429 platform.linkedin.rate_limit`. It costs no SocialAPI credit |

## Permissions

SocialAPI's LinkedIn app requests these scopes at connect. You apply for no app review.

| Scope | Used for |
|---|---|
| `openid`, `profile` | Identify the member: name, picture, and ID |
| `w_member_social` | Publish posts as the member |
