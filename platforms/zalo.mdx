SocialAPI connects a Zalo Official Account (OA), the business account on Zalo, Vietnam's messaging app. It reads and answers the direct messages (DMs) that people send to the OA, and it publishes and deletes OA articles. SocialAPI's own Zalo app connects the account, so you register no Zalo app and complete no step in the Zalo developer portal: see [Platform apps](/guides/platform-credentials).

## At a glance

| Field | Value |
|---|---|
| Platform slug | `zalo` |
| Auth | OAuth 2.0 with PKCE. An administrator of the Official Account signs in to Zalo and approves |
| Platform API | Zalo Official Account Open API |
| Status | Available on every plan |

## Capabilities

An unsupported call returns `501 resource.not_supported`.

| Feature | Status | Condition |
|---|---|---|
| Publish an article | Yes | Text only. See [Zalo publishing](/platforms/zalo/publishing) |
| Publish a video | No | A `url` or `media_id` item on a Zalo target is ignored, and the article publishes with `text` only. A `platform_attachment_id` item fails the target with `422 publishing.media.unsupported_source` |
| Schedule a post | Yes | `scheduled_at` on the post |
| First comment on a post | No | `first_comment` is ignored |
| Update a published article | No | `PATCH /v1/posts/{post_id}` returns `409 post.state_invalid` for a published article. A `draft`, `scheduled`, or `failed` post can be edited before it publishes. To correct an article, delete it and publish a new one |
| Delete a published article | Yes | |
| List posts | Yes | Articles of type `normal`. See [List posts](/platforms/zalo/publishing#6-retrieve-posts) |
| DMs: list, read, send | Yes | Sending needs the person to have interacted with the OA within 7 days: see [The 7-day messaging window](/platforms/zalo/messages#the-7-day-messaging-window) |
| DM attachments | Partial | A `url` or `media_id` attachment is sent as an image unless its `type` is `gif` or `sticker`, which are not supported that way. Send a sticker by its ID as a `platform_attachment_id`. Files cannot be sent. See [Attachments](/platforms/zalo/messages#attachments) |
| Buttons and a card | Partial | SocialAPI sends `buttons`, and the first entry of `cards` as a contact request card. It ignores `quick_replies` and `list_sections` |
| Quote a message in a DM | Yes | `reply_to_message_id` on the send request. It applies to the first message sent |
| React to a DM | No | `501 resource.not_supported` |
| Typing indicators and seen receipts | No | `501 resource.not_supported` |
| Private reply to a comment | No | Zalo has no comments |
| Comments | No | Zalo has no public comments API |
| Mentions | No | Zalo has no public mentions API |
| Reviews | No | Zalo has no public reviews API |
| Automations | No | Automations run on Instagram and Facebook accounts only. `422 automation.platform_unsupported` |
| Analytics | Partial | Post metrics: views and shares only. Likes, comments, and saves stay `0`. No account summary. See [Zalo publishing](/platforms/zalo/publishing#6-retrieve-posts) and [Analytics](/guides/analytics) |
| Platform quota | No | `GET /v1/accounts/{account_id}/limits` returns no usable quota for a Zalo account: do not call it. See [Rate limits](/guides/rate-limits#read-a-platforms-remaining-quota) |
| Webhook events | Partial | `dm.received` fires for text messages only. The `post.*` and `account.*` events fire as on other platforms. See [Webhook events](#webhook-events) |

The capability matrix for every platform is on [Supported platforms](/platforms/overview).

## Connect an account

A Zalo Official Account connects through the shared OAuth flow in [Connect accounts](/guides/connect-accounts): send `platform: "zalo"` to `POST /v1/accounts/connect`, send the administrator to the returned authorization URL, and read the connected account's ID from your redirect.

Each Zalo authorization covers exactly one Official Account. The connected account's `username` is the Official Account's ID and its `display_name` is the OA's name. To connect a second Official Account, run the flow again.

SocialAPI renews Zalo's access tokens (valid for 25 hours) for you. When renewal fails, the first call that fails returns `401 platform.zalo.auth` and the account is marked `token_expired`. Every later call that acts on the account returns `403 account.reconnection_required` until you reconnect it. Reconnect with the same `brand_id`.

## Direct messages

SocialAPI lists the Official Account's conversations, reads their messages, and sends replies to people who interacted with the OA within the last 7 days. Conversations, attachments, buttons, the messaging window, and DM errors are on [Zalo direct messages](/platforms/zalo/messages).

## Webhook events

Zalo emits `dm.received` when a person sends the OA a text message: see [Zalo direct messages](/platforms/zalo/messages#events). Zalo also emits the `post.*` events for articles you publish through SocialAPI, `account.connected` when you connect the account, and `account.disconnected` with `reason: "posts_sync_auth_failed"` when SocialAPI finds that the login needs renewing. A call that returns `401 platform.zalo.auth` does not send it: read the account's `status` to detect it.

## Limits

| Limit | Value |
|---|---|
| Articles imported when you connect or sync an account | 20 most recent |
| Article title | 150 characters |
| Posts | 25 per hour and 50 per 24 hours for each account: see [Posting velocity caps](/guides/rate-limits#posting-velocity-caps) |

DM limits are on [Zalo direct messages](/platforms/zalo/messages#limits). Zalo limits requests per minute for each app and each Official Account, sets usage quotas per feature, and limits how many messages one person can receive from the OA. When one is used up, the call fails with `429 platform.zalo.rate_limit` and no `Retry-After` header: wait at least 60 seconds, then retry with exponential backoff. A refused send costs 1 interaction credit. When retries with exponential backoff keep returning it, stop: the Official Account's or the person's quota is used up.

## Scopes

SocialAPI sends no scope list to Zalo. The administrator of the Official Account approves the scopes that Zalo's consent screen lists for SocialAPI's Zalo app. Disconnecting the account from SocialAPI does not revoke that authorization on Zalo: the administrator removes it on Zalo. The account supports the `posts.read`, `posts.write`, `messages.read`, and `messages.write` [permissions](/guides/permissions), which SocialAPI alone enforces.
