title: Supported platforms
description: Which operations each SocialAPI platform supports for the inbox, Automations, publishing, analytics, and webhook events, in one matrix per feature area.
---

SocialAPI connects Instagram, Facebook, Threads, Google Business Profile, TikTok, LinkedIn, X / Twitter, Telegram, WhatsApp, Zalo, Bluesky, Pinterest, and YouTube through one API. Trustpilot is marked Coming soon and cannot be connected. Most platforms connect through SocialAPI's own platform app, so you register nothing with the platform. Telegram connects with a bot token from @BotFather, Bluesky with an app password, and X / Twitter through an X developer app that you create. See [Platform apps](/guides/platform-credentials) for who owns the app for each platform.

Every platform and every operation is available on every plan, except WhatsApp template messages, which need a paid plan (`403 whatsapp.paid_plan_required` on the Free plan). Plans otherwise differ only in resource limits: see [Plans](/guides/plans). Each platform page holds a Capabilities table with the condition behind every cell below.

When you call an operation a platform does not support, SocialAPI returns `501 resource.not_supported`. That is a platform limit, not a mistake in your integration, so handle the 501 instead of branching per platform. An Automation on an account that does not support Automations returns `422 automation.platform_unsupported`, and a reviews call on a platform without reviews returns `422 account.platform_unsupported`.

The cells have 5 values:

| Value | Meaning |
|---|---|
| Yes | Supported |
| No | Not supported. The call returns an error, or the feature does not exist on the platform |
| Partial | Supported with a limit on what it covers |
| Conditional | Supported only when a condition holds, such as an action on your own comment |
| Beta | Supported for accounts where the platform has granted the permission |

The condition behind every Partial, Conditional, and Beta cell is on the platform page. Each comment returned by the inbox also carries a `capabilities` object that tells you which actions the platform allows for it: see [Comments](/guides/comments).
